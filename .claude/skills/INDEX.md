## Combinations that work for this project

- **Building or reworking the landing page:** follow AGORAX_BUILD_PLAN.md. `impeccable` (document → critique → shape → build → animate → adapt) with `interaction-design` and `responsive-design`. Do not use `brand-landingpage` here: it needs Google Stitch and is for pages with no existing design tokens.
- **Any UI that looks generic:** `impeccable` plus `ui-ux-pro-max` for a palette and type system that is not the default.
- **A bug:** `systematic-debugging`, then `verification-before-completion` before it claims to be fixed.
- **Splitting App.tsx:** `composition-patterns` plus `react-best-practices`.
- **Survey and interview data:** `meeting-insights-analyzer`, then `validate-idea`.
- **Innokite application answers:** `market-sizing-analysis`, `competitive-landscape`, `startup-metrics-framework`, `startup-financial-modeling`.
- **Any text students will read:** `humanizer` or `avoid-ai-writing`.
- **Before touching contact data:** `gdpr-data-handling`.
